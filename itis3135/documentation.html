HTML Basics

HTML stands for HyperText Markup Language and is used to structure content on a webpage. It defines headings, paragraphs, links, images, lists, forms, and other page elements.

A basic document begins with <!DOCTYPE html> and includes the <html>, <head>, and <body> elements.

Common Elements

Some of the most common HTML elements include headings, paragraphs, anchor links, images, lists, and semantic layout elements such as header, main, section, article, and footer. 

<h1>Main Heading</h1>
<p>This is a paragraph.</p>
<a href="https://example.com">Visit Example</a>

Forms

Forms allow users to enter data. Common form controls include text inputs, email inputs, number inputs, radio buttons, checkboxes, textareas, and submit buttons. 

<form>
  <label for="name">Name</label>
  <input type="text" id="name" name="name">
  <button type="submit">Submit</button>
</form>

CSS Styling

CSS is used to style the structure created with HTML. It can change colors, layout, spacing, typography, borders, and responsiveness across devices. 

body {
  font-family: Arial, sans-serif;
  margin: 0;
  padding: 0;
}

h1 {
  color: navy;
}

Best Practices

Good web pages use semantic HTML, meaningful headings, accessible labels, readable contrast, organized CSS, and responsive layout principles.

  • Use clear and descriptive headings.
  • Keep navigation easy to understand.
  • Use labels for all form inputs.
  • Write clean and readable code.
  • Test your work across different screen sizes.
